# Simple Interest Calculator

## Project Description

This project is a simple interest calculator implemented using Bash.

The calculator takes the following inputs from the user:

- Principal amount
- Rate of interest
- Time period

It calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Usage

The user enters the principal amount, rate of interest, and time period. The calculator then displays the calculated simple interest.

## Formula

SI = (P × R × T) / 100
